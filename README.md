# Save the Newts 3D

Rescue California newts crossing a road at night.

![Save the Newts 3D](assets/game_poster.png)

**Controls:** WASD to move · Mouse to look · Walk into newts to rescue them

**Run:** `npm ci && npm run vendor && npm start` → http://localhost:3000

Android APKs are on the [Releases](https://github.com/karangattu/save-the-newts-3d/releases) page.
